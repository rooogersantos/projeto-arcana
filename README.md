# ARCANA

Sistema de acesso e gerenciamento de usuários desenvolvido em React.
Projeto prático desenvolvido para a disciplina de Desenvolvimento Front-End 2 do curso de Análise e Desenvolvimento de Sistemas do IPOG.

## Tecnologias
- React
- JavaScript
- HTML
- CSS
- React Router
- Vite
- LocalStorage

## Funcionalidades
- Login
- Cadastro de usuários
- Recuperação de acesso
- Perfil
- Gerenciamento de conta
- Alteração de senha
- Dashboard
- Status da conta
- Gerenciamento de usuários
- Controle de permissões entre Administrador, Moderador e Usuário

## Como executar

```bash
npm install
npm run dev
